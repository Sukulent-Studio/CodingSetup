# Инструкция для ИИ-агента: оформление документов в Typst

Этот документ описывает сборку отчётов по ГОСТ 7.32-2017 с локальными пакетами Typst. Все зависимости подключаются через `@local`;

Компоненты разделены по назначению:

- `modern-g7-32` задаёт оформление по ГОСТ 7.32-2017: поля, нумерацию, подписи, заголовки, содержание и приложения.
- `gost-table` создаёт длинные таблицы, повторяет их шапку и добавляет надпись «Продолжение таблицы N».
- `tituls` содержит шаблоны внешних титульных листов.
- `cetz` используется для создания схем и диаграмм непосредственно в Typst.

Встроенный титульный лист `modern-g7-32` отключай параметром `hide-title: true`, кроме случая, когда пользователь явно выбрал его. Титульники из `tituls` являются отдельными шаблонами.

---

## 1. Что нужно для сборки

- Typst 0.12 или новее (`typst --version`).
- Локальные пакеты `modern-g7-32`, `gost-table`, `tituls` и, если нужны схемы, `cetz`. Проверяй версии в `typst.toml` соответствующего пакета; не угадывай их и не устанавливай зависимости без разрешения.
- Шрифт: если установленная версия шаблона не задаёт семейство шрифта, укажи `#set text(font: ("Times New Roman", "Liberation Serif"))`. Добавляй `--font-path`, если шрифты лежат в нестандартной папке.

Сборка: `typst compile main.typ main.pdf`.

## 2. Каркас документа

```typst
#import "@local/modern-g7-32:0.2.0": (
  gost,
  abstract,
  appendixes,
  structure-heading,
  enum-numbering,
) // импортируй только то, что используешь
#import "@local/gost-table:<версия из typst.toml>": (
  long-table,
  table-continuation,
)

#set text(font: ("Times New Roman", "Liberation Serif"))

#show: gost.with(hide-title: true)   // 1. шаблон, титульник отключён
#show: table-continuation            // 2. модуль таблиц — ПОСЛЕ шаблона, один раз

#abstract("ключевое слово", "ещё одно")[
  Текст реферата.
]

#outline()

= Введение
Текст введения.

= Основная часть
== Подраздел
Текст со ссылкой на источник @kot.

= Заключение
Текст заключения.

#bibliography("refs.bib")

#show: appendixes                    // всё ниже — приложения
= Первое приложение
Текст приложения.
```

Заменяй `<версия из typst.toml>` фактической версией установленного пакета. Импортируй каждый модуль отдельно через `@local`; не используй относительные импорты.

Порядок директив важен:

- `#show: gost.with(...)` идёт первым, `#show: table-continuation` сразу за ним.
- `table-continuation` вызывается **один раз**.
- `#show: appendixes` ставится после списка источников; всё ниже него считается приложениями.

С `hide-title: true` параметры встроенного титульника не нужны. Первая страница документа — реферат или содержание.

### Внешний титульный лист

Подключай титульники отдельно из локального пакета `tituls`. Поля шаблонов перечислены в `${HOME}/.config/opencode/docs/report-maker/tituls.md`; пропущенные поля используют значения по умолчанию шаблона. Этот путь относится к каталогу документации агента, а не к каталогу `docs/` проекта.

```typst
#import "@local/tituls:0.1.0": titul

#titul("MMITE", (
  group: [ПИН-241],
  student: [И. И. Иванов],
))
```

Сверяй версию импорта с `tituls/typst.toml`. Не подставляй внешние титульники одновременно со встроенным титульным листом `modern-g7-32`.

## 3. Что шаблон делает сам (не дублировать)

Не пишите свои `set`/`show`-правила для этого, иначе они вступят в конфликт с шаблоном:

| Что | Как устроено в шаблоне |
|---|---|
| Текст | кегль 14 pt, язык `ru`, выравнивание по ширине, красная строка 1,25 см, переносы слов отключены |
| Страница | поля: левое 30 мм, правое 15 мм, верх и низ по 20 мм; номер страницы по центру внизу (колонтитул-**футер**) |
| Заголовки | нумерация `1`, `1.1`; каждый заголовок 1-го уровня начинается с новой страницы |
| Структурные заголовки | «Введение», «Заключение», «Реферат», «Содержание», «Список использованных источников» и др. — по центру, прописными, без номера |
| Рисунки | подпись снизу: «Рисунок 1 — Название» |
| Таблицы | подпись сверху по левому краю: «Таблица 1 — Название» |
| Формулы | нумерация `(1)` |
| Списки | маркер «–»; для нумерованных русская буквенная нумерация через `enum-numbering` |
| Источники | стиль `gost-r-705-2008-numeric`, заголовок «Список использованных источников» |

**Запрещено** в основном документе (ломает вёрстку шаблона или модуля):

- `#set page(footer: ...)` — переопределит нумерацию страниц.
- `#set page(header: ...)` — переопределит колонтитул с надписью «Продолжение таблицы». Свой верхний колонтитул передавайте только через `table-continuation.with(base-header: [...])`.
- `#set figure.caption(...)`, `#show figure.caption: ...` без `where(kind: ...)` — заденет подписи рисунков (так ломалось выравнивание подписей).
- `#set par(justify: ...)`, `#set text(size: ...)` глобально — меняют оформление всего отчёта.

### Структурные заголовки

Заголовок первого уровня с текстом из списка (`Введение`, `Заключение` и т. п.) автоматически становится структурным (без номера, по центру):

```typst
= Введение
= Заключение
```



### Реферат

`#abstract("ключ1", "ключ2")[текст]` — сам считает страницы, рисунки, таблицы, источники и приложения («Отчёт 6 с., 1 рис., 3 табл., 1 прил.»). Отключить счётчик: `#abstract(count: false, ...)[...]`. Счётчик таблиц учитывает все `long-table`.

### Рисунки

```typst
#figure(image("assets/scheme.png", width: 80%), caption: [Структурная схема]) <fig-scheme>
```

Подпись и слово «Рисунок» шаблон ставит сам. Не задавайте `supplement` вручную.

### Списки

```typst
#set enum(numbering: enum-numbering)   // а) б) в) вместо 1. 2. 3.
+ первый пункт
+ второй пункт

- маркированный пункт
```

### Формулы

```typst
$ x = y^2 $ <eq-main>
```

Нумерация `(1)` добавляется автоматически.

### Приложения

После `#show: appendixes` каждый `= Заголовок` — отдельное приложение: «ПРИЛОЖЕНИЕ А», «ПРИЛОЖЕНИЕ Б» и т. д. Рисунки, таблицы и формулы внутри нумеруются заново с буквой: «Таблица А.1», «Рисунок Б.2». Модуль таблиц выводит надпись продолжения в том же формате («Продолжение таблицы А.1»).

## 4. Ссылки в тексте

В шаблоне задано `set ref(supplement: none)`, поэтому `@метка` выводит **только номер**, без слова:

| Написано | Получится |
|---|---|
| `@tbl-a` | `1` |
| `@img` | `1` |
| `@eq-main` | `1` (без скобок!) |
| `@tbl-b` (в приложении) | `А.1` |
| `@kot` (источник) | `[1]` |

Поэтому слово пишите сами:

```typst
Результаты приведены в таблице @tbl-a, схема показана на рисунке @img.
Согласно формуле (@eq-main) значение равно ...
```

Метка ставится сразу после закрывающей скобки `figure`/`long-table`/формулы: `) <tbl-a>`.

## 5. Пакет таблиц `gost-table`

### 5.1. `long-table(...)`

Строит `figure` с таблицей внутри. Подпись, нумерацию, положение подписи и разделитель задаёт шаблон.

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `caption` | `none` | подпись таблицы, контент `[...]` |
| `columns` | `auto` | как в `table`: число или массив ширин, например `(1.3cm, 3.6cm, 1fr)` |
| `header` | `()` | массив ячеек шапки, например `([Показатель], [Значение])`. Пусто или `none` — таблица **без заголовка** |
| `number-rows` | `false` | `true` — добавить первым столбцом порядковый номер строки |
| `hyphenate` | `true` | переносы слов внутри таблицы (иначе длинные слова вылезают из узких колонок) |
| `caption-at-edge` | `auto` | подпись по левому краю страницы вместо левого края таблицы (см. 5.3) |
| остальные именованные | — | передаются в `table` без изменений: `align`, `inset`, `stroke`, `fill`, `rows` и т. д. |
| позиционные | — | строки таблицы (см. ниже) |

Возвращает `figure`, поэтому после вызова можно ставить метку и ссылаться на таблицу.

### 5.2. Форматы строк

**Основной формат — блоки.** Каждая строка — массив ячеек в круглых скобках:

```typst
#long-table(
  caption: [Классификация системы «грузовик»],
  columns: (1.3cm, 3.6cm, 3.4cm, 1fr),
  header: ([№ п/п], [Критерий], [Класс], [Характеристика]),
  number-rows: true,                       // номер добавится сам, в блоках его писать не нужно
  (
    [По взаимодействию с внешней средой],
    [Открытая],
    [Грузовик постоянно обменивается со средой ...],
  ),
  (
    [По структуре],
    [Сложная],
    [Грузовик состоит из тысяч деталей ...],
  ),
) <tbl-truck>
```

Допустимы также:

- **массив блоков одним аргументом:** `long-table(caption: ..., columns: ..., rows)`, где `rows = ((...), (...))`;
- **плоский список ячеек** (старый формат): `long-table(columns: 2, [a], [b], [c], [d])`.

Правила:

- В одном вызове не смешивайте блоки и плоские ячейки.
- Каждая ячейка — контент в `[...]`. Пустая ячейка — `[]`.
- Длина блока должна равняться числу столбцов. При `number-rows: true` в `columns` учитывайте столбец с номером, а в блоке номер не пишите.
- Строка из одной ячейки в блочном формате требует запятой: `([текст],)`. Без запятой это не массив, а контент.
- Объединённые ячейки работают как в обычном Typst: `(table.cell(colspan: 3)[Общая строка],),`.
- Таблица без шапки:

```typst
#long-table(
  caption: [Параметры системы],
  columns: (1fr, 1fr),
  ([Скорость], [90 км/ч]),
  ([Масса], [12 т]),
) <tbl-params>
```

### 5.3. Подпись по левому краю страницы (`caption-at-edge`)

По умолчанию подпись выровнена по левому краю таблицы. У узкой таблицы, стоящей по центру, подпись окажется посреди страницы. Чтобы подпись стояла у левого поля текста:

```typst
// для всего документа:
#show: table-continuation.with(caption-at-edge: true) // Рекомендую всегда ставить

// для одной таблицы (приоритетнее глобальной настройки):
#long-table(caption: [Узкая таблица], columns: 2, caption-at-edge: true, ...)
```

Таблица остаётся по центру, смещается только подпись. На широких таблицах (например, с колонкой `1fr`) разницы нет.

### 5.4. `table-continuation`

Подключается как `#show: table-continuation` (после `gost`). Добавляет в верхний колонтитул надпись справа «Продолжение таблицы N» на каждой странице, куда перенеслась таблица.

| Параметр | Назначение |
|---|---|
| `prefix` | текст надписи, по умолчанию `[Продолжение таблицы]` |
| `base-header` | ваш верхний колонтитул (выводится выше надписи) |
| `caption-at-edge` | `true` — подписи таблиц по левому краю страницы для всего документа |

Как это работает: `long-table` ставит невидимые маркеры в начале и конце таблицы; колонтитул проверяет, лежит ли текущая страница внутри такого диапазона. Номер берётся в том же формате, что и в подписи (`1`, `А.1`).

Ограничения:

- Работает только для таблиц, созданных через `long-table`. Обычные `#figure(table(...))` надпись продолжения не получат.
- Надпись находится в области колонтитула над повторённой шапкой.
- Если таблица целиком помещается на странице, надписи нет.

## 6. Схемы и диаграммы с Cetz

Создавай векторные схемы и диаграммы средствами локального пакета `cetz`. Перед написанием схемы прочитай документацию и примеры установленной версии Cetz (`${HOME}/.config/opencode/docs/report-maker/manual.pdf`), затем импортируй пакет через `@local/cetz:<версия из typst.toml>`. Все пути к руководствам в этом разделе указывают на каталог документации агента, а не на `docs/` внутри проекта. Сохраняй схемы в исходном `.typ` отчёта или в отдельных `.typ` файлах каталога `diagrams/`. Если Cetz размещён непосредственно в документе, экспортировать схему в отдельное изображение не нужно.

## 7. Типичные ошибки и их причины

| Симптом | Причина | Что делать |
|---|---|---|
| Подписи рисунков уехали влево | глобальное `show figure.caption: set align(left)` | убрать; для таблиц шаблон уже выравнивает влево |
| В тексте «табл. 1» не получилось, видно только «1» | `ref(supplement: none)` в шаблоне | писать слово вручную: `таблице @tbl-a` |
| Нет надписи «Продолжение таблицы» | таблица не через `long-table`; `table-continuation` не подключён или подключён до `gost`; своё `set page(header: ...)` | см. разделы 2, 3, 5.4 |
| Надпись показывает «1» вместо «А.1» | старая версия модуля | проверь версию локального пакета `gost-table` |
| `unexpected argument: hyphenate` | `hyphenate` — параметр `text`, не `par` | `set text(hyphenate: true)` |
| Слова вылезают из узкого столбца | нет переносов или колонка уже слова | оставить `hyphenate: true`, расширить колонку, убедиться в `lang: "ru"` (шаблон ставит его сам) |
| `caption-at-edge: true` в `table-continuation` ничего не меняет | устаревшая версия модуля, где повторный вызов `table-continuation` без опции сбрасывал её | проверь версию локального `gost-table` и вызывай `table-continuation` один раз: `#show: table-continuation.with(caption-at-edge: true)` |
| Лишний или смещённый столбец | при `number-rows: true` в блоках дописан номер, или `columns` не учитывает номер | убрать номер из блоков, увеличить `columns` на 1 |
| В колонтитуле пропал номер страницы | свой `set page(footer: ...)` | убрать |
