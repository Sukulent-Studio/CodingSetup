# Поля титульных листов

Поля передаются вторым аргументом функции `titul()` в `main.typ` как словарь. Все значения должны быть Typst-содержимым, обычно в квадратных скобках.

```typ
#titul("MMITE", (
  group: [ПИН-241],
  student: [И. И. Иванов],
))
```

Необязательные поля, которые не переданы, используют значения по умолчанию, заданные в соответствующем шаблоне.

## Общие поля

| Поле | Назначение | Шаблоны |
| --- | --- | --- |
| `org` | Полное наименование организации | ASOIU, MMITE |
| `university` | Наименование университета | ASOIU, MMITE |
| `department` | Наименование кафедры | ASOIU, MMITE |
| `doc-type` | Тип или название работы | ASOIU, MMITE |
| `discipline` | Название дисциплины | ASOIU, MMITE |
| `group` | Учебная группа | ASOIU, MMITE |
| `student` | ФИО исполнителя | ASOIU, MMITE |
| `teacher` | ФИО преподавателя/проверяющего | ASOIU, MMITE |
| `city` | Город | ASOIU, MMITE |
| `year` | Год | ASOIU, MMITE |

## Только ASOIU

| Поле | Назначение |
| --- | --- |
| `work` | Название или номер работы (сейчас не выводится шаблоном) |
| `doc-name` | Название документа |
| `cipher` | Шифр работы |
| `direction` | Направление подготовки |
| `teacher-role` | Должность/учёная степень преподавателя |
| `student-role` | Подпись роли исполнителя в блоке подписей |
| `student-signature` | ФИО исполнителя в блоке подписей |

## Только MMITE

Отдельных полей нет. Переданные поля `group`, `student` и `teacher` используются в правом блоке исполнителя и проверяющего.
